What is this?

If you use a terminal emulator under the X Window System, this site helps you build a color scheme for your terminal.

Save the downloaded file as ~/.Xdefaults, load it with xrdb -load ~/.Xdefaults, then start your terminal with urxvtc -name dark (replacing dark with your scheme name).
