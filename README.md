# TermScheme

Build a color scheme for your terminal. Choose colors with native color
controls or enter hexadecimal values, preview the result, and download an
Xresources file. The generated resource text is also shown on the page for
copying.

The site is a static HTML page with plain JavaScript and has no external
runtime dependencies.
